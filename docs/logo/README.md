# FreeFBM logo

The mark is a speech bubble that is an objectified fact type: the rounded frame ORM draws around a fact type, with a tail, holding two role boxes under one uniqueness bar. What people say, held as a fact (Jan, 2026-11-22).

| File | Use |
|---|---|
| `logo.svg` | the mark on light backgrounds |
| `logo-on-dark.svg` | the mark on dark backgrounds (no outline) |
| `icon.svg` | app icon master (1024, macOS-style tile with margin); `build/icon.icns`, `build/icon.png` and the ico's 128–256 px images come from it |
| `icon-small.svg` | app icon for 16–32 px (solid role boxes, thicker bar), used in `build/icon.ico` |
| `banner.svg`, `banner-on-dark.svg` | mark and name with the line "Each fact, said and stated" (README, web page) |
| `banner-plain.svg` | mark and name only |
| `slide.svg` | picture for slides: the fact as a diagram, a sentence and a formula |

Colours: navy `#1d2b4f`, purple `#7b2d8e` (light purple `#c79be0` on dark), amber `#e3a72f` in the icon. The name is set in Fraunces Bold ("Free" purple, "FBM" navy), the line in IBM Plex Sans Medium, the app's own fonts; text in the SVGs is converted to outlines, so they need no fonts.
