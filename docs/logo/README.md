# FreeFBM logo

The mark is a speech bubble that is an objectified fact type: the rounded frame ORM draws around a fact type, with a tail, holding two role boxes under one uniqueness bar. What people say, held as a fact (Jan, 2026-11-22).

| File | Use |
|---|---|
| `logo.svg` | the mark on light backgrounds |
| `logo-on-dark.svg` | the mark on dark backgrounds (no outline) |
| `icon.svg` | app icon master (1024, macOS-style tile with margin, 824 px body): a mid tan parchment with a gentle gradient, light at the top (`#ebdcb6` to `#cdb682`), a faint grid and no border, and bold lines (Jan, 2026-11-24: the thick dark border made the tile look smaller and drab in the Dock; earlier, 2026-11-22, the navy tile was too dark on a dark Dock and the light parchment too pale from a distance); `build/icon.icns`, `build/icon.png` and the 128–1024 px images come from it |
| `icon-small.svg` | app icon for 16–32 px (no grid, solid role boxes, thicker bar, the tile to the edge); 48–64 px use the master without margin or grid |
| `banner.svg`, `banner-on-dark.svg` | mark and name with the line "Each fact, said and stated" (README, web page) |
| `banner-plain.svg` | mark and name only |
| `slide.svg` | picture for slides: the fact as a diagram, a sentence and a formula |
| `ffbm.svg`, `ffbm-small.svg` | document icon for .ffbm files (`build/ffbm.icns`, `build/ffbm.ico`; the small one for 16–64 px) |

Colours: navy `#1d2b4f`, purple `#7b2d8e` (light purple `#c79be0` on dark), amber `#e3a72f` (the earlier navy icon), parchment `#f5f0e8` (the app's canvas), mid tan `#dbc89c` (the gradient `#ebdcb6` to `#cdb682` on the app icon) as the icon's ground. The name is set in Fraunces Bold ("Free" purple, "FBM" navy), the line in IBM Plex Sans Medium, the app's own fonts; text in the SVGs is converted to outlines, so they need no fonts.
