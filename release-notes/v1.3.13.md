# FreeFBM 1.3.13

FreeFBM has a logo. This release brings the new app and document icons, the logo in the app, an About window, and double-click opening of `.ffbm` files.

## ⚠️ Files

- Files from 1.3.8 open in 1.3.13 and the other way round. The file format has not changed.

## The FreeFBM logo

- The logo is a speech bubble that is also an objectified fact type. It is the new **app icon**, on parchment with a navy border, so it stands out in a dark Dock or taskbar.
- The logo and the FreeFBM name are in the toolbar and on the welcome screen. The welcome screen now describes FreeFBM as "Fact-based modelling: ORM2 schemas, tables, and the mappings between them".
- An **empty diagram** shows a faint logo with a hint on how to fill it. It goes away as soon as something is placed on the diagram.

## About window and file icons

- **About FreeFBM** (FreeFBM menu on macOS, Help menu on Windows and Linux) shows the version and the licence, with a link to FreeFBM on GitHub.
- `.ffbm` files have their own **document icon**. Double-clicking one, choosing Open With, or dropping it on the Dock icon opens it in FreeFBM. The installer registers the file type.
- The window and the verbalisation workbench are now titled FreeFBM instead of "ORM2 Editor".

## Smaller changes

- The Inspector no longer offers a schema kind selector for ORM2 schemas. A relational schema gets a short line saying what it is, with a **Treat as ORM2** button.

## Downloads

- **macOS**: universal `.dmg` and `.zip` (Apple silicon and Intel), unsigned, so macOS warns the first time you open it
- **Windows**: `FreeFBM-1.3.13-windows-setup.exe`
- **Linux**: `.AppImage` and `.deb` (x64)
