# FreeFBM 1.3.8

A small release after 1.3: clearer constraint sentences and formulas, and the design documents that describe the logic behind FreeFBM. There is nothing new to learn in the app.

## ⚠️ Files

- Files from 1.3.0 open in 1.3.8 and the other way round. The file format has not changed.

## Clearer constraint sentences

- **If … then … sentences** now introduce each object at its first mention with "some" and refer back to it with "that", as NORMA does: "If some Course₁ is a prerequisite for some Course₂ and that Course₂ is a prerequisite for some Course₃ then that Course₁ is not a prerequisite for that Course₃." All seven languages follow this ("ein Kurs" … "dieser Kurs" in German).
- English no longer writes "that that" when a relative clause refers back to an object: "each Course that Student enrols in".

## Shorter join path formulas

- A subset, equality or exclusion constraint whose join path goes through an objectified fact type now names only the link fact types the path uses. For example, "If Staff member teaches some Offering that involves Course then Staff member is qualified to teach Course" no longer adds "and involves some Term".

## Design documents

- **FBM logic** (`docs/logic/fbm-logic.tex`): the logic FreeFBM implements, with its syntax, typing, semantics, data operators, the formula of each constraint kind, queries, derivation rules and notation, and the reasons for each choice.
- **Verbalisation, version 10** (`docs/verbalisation/verbalisation.tex`): the whole verbalisation pipeline, with the rule language as a reference.
- **Schema mappings** (`docs/logic/schema-mappings.tex`) now uses the notation of FBM logic and describes constraint accounting as the app does it.
