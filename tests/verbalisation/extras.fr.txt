# Derivation rule · Student is a TeachingAssistant if and only if …
∀ Student (TeachingAssistant(Student) ↔ ∃ Course (Student assists in Course))
Étudiant est un TeachingAssistant si et seulement si Étudiant assiste à un Cours.

# Semi-derivation rule · Student is a BusyStudent if …
∀ Student ((∃^{≥4} Course (Student enrols in Course)) → BusyStudent(Student))
Chaque Étudiant qui suit au moins 4 Cours est un BusyStudent.

# Derivation rule · Course is a HeavyCourse if and only if …
∀ Course (HeavyCourse(Course) ↔ ∃ Credits ((Course is worth Credits) ∧ Credits ≥ 30))
Cours est un HeavyCourse si et seulement si Cours a un Nombre de crédits qui est au moins 30.

# Derivation rule · Student is a FreeStudent if and only if …
∀ Student (FreeStudent(Student) ↔ ¬(∃ Course (Student enrols in Course)))
Étudiant est un FreeStudent si et seulement si Étudiant ne suit aucun Cours.

# Derivation rule · Course is an IntroCourse if and only if …
∀ Course (IntroCourse(Course) ↔ ∃ CourseTitle ((Course has CourseTitle) ∧ startsWith(CourseTitle, 'Introduction')))
Cours est un IntroCourse si et seulement si Cours a un Intitulé de cours qui commence par 'Introduction'.

# Semi-derivation rule · Course is a LongTitleCourse if …
∀ Course ((∃ CourseTitle ((Course has CourseTitle) ∧ length(CourseTitle) > 40)) → LongTitleCourse(Course))
Chaque Cours qui a un Intitulé de cours tel que la longueur de cet Intitulé de cours est supérieur à 40 est un LongTitleCourse.

# Value range (deontic) · Score
O(∀ Score ((Score > 0 ∧ Score ≤ 100) ∨ Score > 200))
Il est obligatoire que les valeurs possibles de Score sont plus de 0 et au plus 100, plus de 200.

# Cardinality · Professor
∃^{2..20} Professor ⊤
Il existe au moins 2 et au plus 20 Professeurs.

# Cardinality (deontic) · Building
O(∃^{=3} Building ⊤)
Il est obligatoire qu'il existe exactement 3 Bâtiments.

# Cardinality · Course
∃^{≤100} Course ⊤
Il existe au plus 100 Cours.

# Cardinality (role 2) · Student enrols in Course
∃^{≤50} Course ∃ Student (Student enrols in Course)
Il existe au plus 50 Cours qu'un Étudiant suit.

# Cardinality (role 1) (deontic) · Staff coordinates Course
O(∃^{≥5} Staff ∃ Course (Staff coordinates Course))
Il est obligatoire qu'il existe au moins 5 Membres du personnel qui coordonnent un Cours.

# Derivation rule · Student studies with Staff
∀ Student ∀ Staff ((Student studies with Staff) ↔ ∃ Course ((Student enrols in Course) ∧ (Staff coordinates Course)))
Étudiant studies with Membre du personnel si et seulement si Étudiant suit un Cours que Membre du personnel coordonne.

# Derivation rule, every derived fact holds · Student has TotalCredits
∀ Student ∃ TotalCredits (Student has TotalCredits)
Chaque Étudiant has un TotalCredits.

# Derivation rule, only derived facts hold · Student has TotalCredits
∀ Student ∀ TotalCredits ((Student has TotalCredits) → TotalCredits ≈ Sum{Credits | Course, Credits : (Student enrols in Course) ∧ (Course is worth Credits)})
Si Étudiant has TotalCredits, alors TotalCredits est la somme des Nombres de crédits que chaque Cours qu'Étudiant suit a.

# Derivation rule, every derived fact holds · Course has EnrolmentCount
∀ Course ∃ EnrolmentCount (Course has EnrolmentCount)
Chaque Cours has un EnrolmentCount.

# Derivation rule, only derived facts hold · Course has EnrolmentCount
∀ Course ∀ EnrolmentCount ((Course has EnrolmentCount) → EnrolmentCount ≈ Count{Student : (Student enrols in Course)})
Si Cours has EnrolmentCount, alors EnrolmentCount est le nombre d'Étudiants qui suivent Cours.

# Semi-derivation rule, every derived fact holds · Student has credit load TotalCredits
∀ Student ∀ Course ∀ Credits (((Student assists in Course) ∧ (Course is worth Credits)) → ∃ TotalCredits ((Student has credit load TotalCredits) ∧ TotalCredits ≈ (Credits + 5) × 2))
Si Étudiant assiste à Cours et Cours a Nombre de crédits, alors Étudiant has credit load un TotalCredits qui est (Nombre de crédits plus 5) fois 2.

# Uniqueness (deontic) · Staff mentors Student
O(∀ Student ∃^{≤1} Staff (Staff mentors Student))
Il est obligatoire que pour chaque Étudiant, au plus un Membre du personnel mentors cet Étudiant.

# Mandatory role (deontic) · Staff mentors Student
O(∀ Student ∃ Staff (Staff mentors Student))
Il est obligatoire que pour chaque Étudiant, un Membre du personnel mentors cet Étudiant.

# Frequency (deontic) · Staff mentors Student
O(∀ Staff ((∃ Student (Staff mentors Student)) → ∃^{≤5} Student (Staff mentors Student)))
Il est obligatoire que chaque Membre du personnel mentors au plus 5 Étudiants.

# Uniqueness · Person has first given PersonName
∀ Person ∃^{≤1} PersonName (Person has first given PersonName)
Chaque Personne a au plus un Nom principal.

# Uniqueness · Person has first given PersonName
∀ PersonName ∃^{≤1} Person (Person has first given PersonName)
Pour chaque Nom, au plus une Personne a ce Nom principal.

# Mandatory role · Person has first given PersonName
∀ Person ∃ PersonName (Person has first given PersonName)
Chaque Personne a un Nom principal.

# Uniqueness · Person has Person -in-law
∀ Person₁ ∃^{≤1} Person₂ (Person₂ has Person₁ -in-law)
Pour chaque Personne₁, au plus une Personne₂ has cette Personne₁-in-law.

# External uniqueness (outer join)
∀ CourseTitle ∀ Staff ∃^{≤1} Course ((Course has CourseTitle) ∧ (Course is run by Staff))
Pour chaque Intitulé de cours et chaque Membre du personnel, au plus un Cours a cet Intitulé de cours et is run by ce Membre du personnel.

# External uniqueness (outer join): no value at position 2
∀ CourseTitle ∃^{≤1} Course ((Course has CourseTitle) ∧ ¬(∃ Staff (Course is run by Staff)))
Pour chaque Intitulé de cours, au plus un Cours a cet Intitulé de cours et n'is run by aucun Membre du personnel.

# Subset (deontic)
O(∀ Student ((∃ Staff (Staff mentors Student)) → ∃ Course (Student enrols in Course)))
Il est obligatoire que chaque Étudiant qu'un Membre du personnel mentors suit un Cours.

# Ring (irreflexive) (deontic)
O(∀ Course ¬(Course is a prerequisite for Course))
Il est obligatoire qu'aucun Cours n'est un prérequis pour lui-même.
