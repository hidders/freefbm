# Derivation rule · Student is a TeachingAssistant if and only if …
∀ Student (TeachingAssistant(Student) ↔ ∃ Course (Student assists in Course))
Étudiant est un Teaching Assistant si et seulement si Étudiant assiste à un Cours.

# Semi-derivation rule · Student is a BusyStudent if …
¬(∃ Student ((∃^{≥4} Course (Student enrols in Course)) ∧ ¬BusyStudent(Student)))
Il est impossible qu'un Étudiant suit au moins 4 Cours et n'est pas un Busy Student.

# Derivation rule · Course is a HeavyCourse if and only if …
∀ Course (HeavyCourse(Course) ↔ ∃ Credits ((Course is worth Credits) ∧ Credits ≥ 30))
Cours est un Heavy Course si et seulement si Cours a un Nombre de crédits qui est au moins 30.

# Derivation rule · Student is a FreeStudent if and only if …
∀ Student (FreeStudent(Student) ↔ ¬(∃ Course (Student enrols in Course)))
Étudiant est un Free Student si et seulement si Étudiant ne suit aucun Cours.

# Derivation rule · Course is an IntroCourse if and only if …
∀ Course (IntroCourse(Course) ↔ ∃ CourseTitle ((Course has CourseTitle) ∧ startsWith(CourseTitle, 'Introduction')))
Cours est un Intro Course si et seulement si Cours a un Intitulé de cours qui commence par 'Introduction'.

# Semi-derivation rule · Course is a LongTitleCourse if …
¬(∃ Course ((∃ CourseTitle ((Course has CourseTitle) ∧ length(CourseTitle) > 40)) ∧ ¬LongTitleCourse(Course)))
Il est impossible qu'un Cours a un Intitulé de cours tel que la longueur de cet Intitulé de cours est supérieur à 40 et n'est pas un Long Title Course.

# Value range (deontic) · Score
F(∃ Score ((Score ≤ 0 ∨ Score > 100) ∧ Score ≤ 200))
Il est interdit qu'un Score est au plus 0 ou est supérieur à 100 et est au plus 200.

# Cardinality · Professor
¬((∃^{≤1} Professor ⊤) ∨ ∃^{>20} Professor ⊤)
Il est impossible qu'il existe au plus un Professeur ou il existe plus de 20 Professeurs.

# Cardinality (deontic) · Building
F((∃^{≤2} Building ⊤) ∨ ∃^{>3} Building ⊤)
Il est interdit qu'il existe au plus 2 Bâtiments ou il existe plus de 3 Bâtiments.

# Cardinality · Course
¬(∃^{>100} Course ⊤)
Il est impossible qu'il existe plus de 100 Cours.

# Cardinality (role 2) · Student enrols in Course
¬(∃^{>50} Course ∃ Student (Student enrols in Course))
Il est impossible qu'il existe plus de 50 Cours qu'un Étudiant suit.

# Cardinality (role 1) (deontic) · Staff coordinates Course
F(∃^{≤4} Staff ∃ Course (Staff coordinates Course))
Il est interdit qu'il existe au plus 4 Membres du personnel qui coordonnent un Cours.

# Derivation rule · Student studies with Staff
∀ Student ∀ Staff ((Student studies with Staff) ↔ ∃ Course ((Student enrols in Course) ∧ (Staff coordinates Course)))
Étudiant studies with Membre du personnel si et seulement si Étudiant suit un Cours que Membre du personnel coordonne.

# Derivation rule, every derived fact holds · Student has TotalCredits
¬(∃ Student ¬(∃ TotalCredits (Student has TotalCredits)))
Il est impossible qu'un Étudiant n'has aucun Total Credits.

# Derivation rule, only derived facts hold · Student has TotalCredits
¬(∃ Student ∃ TotalCredits ((Student has TotalCredits) ∧ TotalCredits ≉ Sum{Credits | Course, Credits : (Student enrols in Course) ∧ (Course is worth Credits)}))
Il est impossible qu'il existe un Étudiant et un Total Credits telles que cet Étudiant has ce Total Credits et ce Total Credits est différent de la somme des Nombres de crédits que chaque Cours que cet Étudiant suit a.

# Derivation rule, every derived fact holds · Course has EnrolmentCount
¬(∃ Course ¬(∃ EnrolmentCount (Course has EnrolmentCount)))
Il est impossible qu'un Cours n'has aucun Enrolment Count.

# Derivation rule, only derived facts hold · Course has EnrolmentCount
¬(∃ Course ∃ EnrolmentCount ((Course has EnrolmentCount) ∧ EnrolmentCount ≉ Count{Student : (Student enrols in Course)}))
Il est impossible qu'il existe un Cours et un Enrolment Count telles que ce Cours has cet Enrolment Count et cet Enrolment Count est différent du nombre d'Étudiants qui suivent ce Cours.

# Semi-derivation rule, every derived fact holds · Student has credit load TotalCredits
¬(∃ Student ∃ Course ∃ Credits ((Student assists in Course) ∧ (Course is worth Credits) ∧ ¬(∃ TotalCredits ((Student has credit load TotalCredits) ∧ TotalCredits ≈ (Credits + 5) × 2))))
Il est impossible qu'il existe un Étudiant, un Cours et un Nombre de crédits telles que cet Étudiant assiste à ce Cours et ce Cours a ce Nombre de crédits et il n'est pas vrai que cet Étudiant has credit load un Total Credits qui est (ce Nombre de crédits plus 5) fois 2.

# Uniqueness (deontic) · Staff mentors Student
F(∃ Student ∃^{>1} Staff (Staff mentors Student))
Il est interdit que plus d'un Membre du personnel mentors le même Étudiant.

# Mandatory role (deontic) · Staff mentors Student
F(∃ Student ¬(∃ Staff (Staff mentors Student)))
Il est interdit qu'il existe un Étudiant tel qu'aucun Membre du personnel ne mentors cet Étudiant.

# Frequency (deontic) · Staff mentors Student
F(∃ Staff ∃^{>5} Student (Staff mentors Student))
Il est interdit qu'un Membre du personnel mentors plus de 5 Étudiants.

# Uniqueness · Person has first given PersonName
¬(∃ Person ∃^{>1} PersonName (Person has first given PersonName))
Il est impossible qu'une Personne a plus d'un Nom principal.

# Uniqueness · Person has first given PersonName
¬(∃ PersonName ∃^{>1} Person (Person has first given PersonName))
Il est impossible que plus d'une Personne a le même Nom principal.

# Mandatory role · Person has first given PersonName
¬(∃ Person ¬(∃ PersonName (Person has first given PersonName)))
Il est impossible qu'une Personne n'a aucun Nom principal.

# Uniqueness · Person has Person -in-law
¬(∃ Person₁ ∃^{>1} Person₂ (Person₂ has Person₁ -in-law))
Il est impossible que plus d'une Personne₂ has la même Personne₁-in-law.

# External uniqueness (outer join)
¬(∃ CourseTitle ∃ Staff ∃^{>1} Course ((Course has CourseTitle) ∧ (Course is run by Staff)))
Il est impossible que plus d'un Cours a le même Intitulé de cours et is run by le même Membre du personnel.

# External uniqueness (outer join): no value at position 2
¬(∃ CourseTitle ∃^{>1} Course ((Course has CourseTitle) ∧ ¬(∃ Staff (Course is run by Staff))))
Il est impossible que plus d'un Cours a le même Intitulé de cours et n'is run by aucun Membre du personnel.

# Subset (deontic)
F(∃ Student ((∃ Staff (Staff mentors Student)) ∧ ¬(∃ Course (Student enrols in Course))))
Il est interdit qu'il existe un Étudiant tel qu'un Membre du personnel mentors cet Étudiant et cet Étudiant ne suit aucun Cours.

# Ring (irreflexive) (deontic)
F(∃ Course (Course is a prerequisite for Course))
Il est interdit qu'un Cours est un prérequis pour lui-même.
