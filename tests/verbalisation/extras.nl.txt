# Derivation rule · Student is a TeachingAssistant if and only if …
∀ Student (TeachingAssistant(Student) ↔ ∃ Course (Student assists in Course))
Student is een TeachingAssistant als en slechts als Student bij een Vak assisteert.

# Semi-derivation rule · Student is a BusyStudent if …
∀ Student ((∃^{≥4} Course (Student enrols in Course)) → BusyStudent(Student))
Elke Student die minstens 4 Vakken volgt, is een BusyStudent.

# Derivation rule · Course is a HeavyCourse if and only if …
∀ Course (HeavyCourse(Course) ↔ ∃ Credits ((Course is worth Credits) ∧ Credits ≥ 30))
Vak is een HeavyCourse als en slechts als Vak een Studielast die minstens 30 is heeft.

# Derivation rule · Student is a FreeStudent if and only if …
∀ Student (FreeStudent(Student) ↔ ¬(∃ Course (Student enrols in Course)))
Student is een FreeStudent als en slechts als Student geen Vak volgt.

# Derivation rule · Course is an IntroCourse if and only if …
∀ Course (IntroCourse(Course) ↔ ∃ CourseTitle ((Course has CourseTitle) ∧ startsWith(CourseTitle, 'Introduction')))
Vak is een IntroCourse als en slechts als Vak een Vaktitel die met 'Introduction' begint heeft.

# Semi-derivation rule · Course is a LongTitleCourse if …
∀ Course ((∃ CourseTitle ((Course has CourseTitle) ∧ length(CourseTitle) > 40)) → LongTitleCourse(Course))
Elk Vak dat een Vaktitel zodanig dat de lengte van die Vaktitel groter dan 40 is heeft, is een LongTitleCourse.

# Value range (deontic) · Score
O(∀ Score ((Score > 0 ∧ Score ≤ 100) ∨ Score > 200))
Het is verplicht dat de mogelijke waarden van Score meer dan 0 en hoogstens 100, meer dan 200 zijn.

# Cardinality · Professor
∃^{2..20} Professor ⊤
Er zijn minstens 2 en hoogstens 20 Hoogleraren.

# Cardinality (deontic) · Building
O(∃^{=3} Building ⊤)
Het is verplicht dat er precies 3 Gebouwen zijn.

# Cardinality · Course
∃^{≤100} Course ⊤
Er zijn hoogstens 100 Vakken.

# Cardinality (role 2) · Student enrols in Course
∃^{≤50} Course ∃ Student (Student enrols in Course)
Er zijn hoogstens 50 Vakken die een Student volgt.

# Cardinality (role 1) (deontic) · Staff coordinates Course
O(∃^{≥5} Staff ∃ Course (Staff coordinates Course))
Het is verplicht dat er minstens 5 Medewerkers die een Vak coördineren zijn.

# Derivation rule · Student studies with Staff
∀ Student ∀ Staff ((Student studies with Staff) ↔ ∃ Course ((Student enrols in Course) ∧ (Staff coordinates Course)))
Student studies with Medewerker als en slechts als Student een Vak dat Medewerker coördineert volgt.

# Derivation rule, every derived fact holds · Student has TotalCredits
∀ Student ∃ TotalCredits (Student has TotalCredits)
Elke Student has een TotalCredits.

# Derivation rule, only derived facts hold · Student has TotalCredits
∀ Student ∀ TotalCredits ((Student has TotalCredits) → TotalCredits ≈ Sum{Credits | Course, Credits : (Student enrols in Course) ∧ (Course is worth Credits)})
Als Student TotalCredits has, dan is TotalCredits de som van de Studielast die elk Vak dat Student volgt heeft.

# Derivation rule, every derived fact holds · Course has EnrolmentCount
∀ Course ∃ EnrolmentCount (Course has EnrolmentCount)
Elk Vak has een EnrolmentCount.

# Derivation rule, only derived facts hold · Course has EnrolmentCount
∀ Course ∀ EnrolmentCount ((Course has EnrolmentCount) → EnrolmentCount ≈ Count{Student : (Student enrols in Course)})
Als Vak EnrolmentCount has, dan is EnrolmentCount het aantal Studenten die Vak volgen.

# Semi-derivation rule, every derived fact holds · Student has credit load TotalCredits
∀ Student ∀ Course ∀ Credits (((Student assists in Course) ∧ (Course is worth Credits)) → ∃ TotalCredits ((Student has credit load TotalCredits) ∧ TotalCredits ≈ (Credits + 5) × 2))
Als Student bij Vak assisteert en Vak Studielast heeft, dan has Student credit load een TotalCredits die (Studielast plus 5) maal 2 is.

# Uniqueness (deontic) · Staff mentors Student
O(∀ Student ∃^{≤1} Staff (Staff mentors Student))
Het is verplicht dat voor elke Student geldt: hoogstens één Medewerker die Student mentors.

# Mandatory role (deontic) · Staff mentors Student
O(∀ Student ∃ Staff (Staff mentors Student))
Het is verplicht dat voor elke Student geldt: een Medewerker die Student mentors.

# Frequency (deontic) · Staff mentors Student
O(∀ Staff ((∃ Student (Staff mentors Student)) → ∃^{≤5} Student (Staff mentors Student)))
Het is verplicht dat elke Medewerker hoogstens 5 Studenten mentors.

# Subset (deontic)
O(∀ Student ((∃ Staff (Staff mentors Student)) → ∃ Course (Student enrols in Course)))
Het is verplicht dat elke Student die een Medewerker mentors, een Vak volgt.

# Ring (irreflexive) (deontic)
O(∀ Course ¬(Course is a prerequisite for Course))
Het is verplicht dat geen Vak een voorkennisvak voor zichzelf is.
