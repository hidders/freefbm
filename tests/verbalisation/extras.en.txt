# Derivation rule · Student is a TeachingAssistant if and only if …
∀ Student (TeachingAssistant(Student) ↔ ∃ Course (Student assists in Course))
Student is a TeachingAssistant if and only if Student assists in some Course.

# Semi-derivation rule · Student is a BusyStudent if …
∀ Student ((∃^{≥4} Course (Student enrols in Course)) → BusyStudent(Student))
Each Student that enrols in at least 4 Courses is a BusyStudent.

# Derivation rule · Course is a HeavyCourse if and only if …
∀ Course (HeavyCourse(Course) ↔ ∃ Credits ((Course is worth Credits) ∧ Credits ≥ 30))
Course is a HeavyCourse if and only if Course is worth some Credits that is at least 30.

# Derivation rule · Student is a FreeStudent if and only if …
∀ Student (FreeStudent(Student) ↔ ¬(∃ Course (Student enrols in Course)))
Student is a FreeStudent if and only if Student does not enrol in any Course.

# Derivation rule · Course is an IntroCourse if and only if …
∀ Course (IntroCourse(Course) ↔ ∃ CourseTitle ((Course has CourseTitle) ∧ startsWith(CourseTitle, 'Introduction')))
Course is an IntroCourse if and only if Course has some CourseTitle that starts with 'Introduction'.

# Semi-derivation rule · Course is a LongTitleCourse if …
∀ Course ((∃ CourseTitle ((Course has CourseTitle) ∧ length(CourseTitle) > 40)) → LongTitleCourse(Course))
Each Course that has some CourseTitle such that the length of that CourseTitle is more than 40 is a LongTitleCourse.

# Value range (deontic) · Score
O(∀ Score ((Score > 0 ∧ Score ≤ 100) ∨ Score > 200))
It is obligatory that the possible values of Score are more than 0 and at most 100, more than 200.

# Cardinality · Professor
∃^{2..20} Professor ⊤
There are at least 2 and at most 20 Professors.

# Cardinality (deontic) · Building
O(∃^{=3} Building ⊤)
It is obligatory that there are exactly 3 Buildings.

# Cardinality · Course
∃^{≤100} Course ⊤
There are at most 100 Courses.

# Cardinality (role 2) · Student enrols in Course
∃^{≤50} Course ∃ Student (Student enrols in Course)
There are at most 50 Courses that some Student enrols in.

# Cardinality (role 1) (deontic) · StaffMember coordinates Course
O(∃^{≥5} StaffMember ∃ Course (StaffMember coordinates Course))
It is obligatory that there are at least 5 Staff members that coordinate some Course.

# Derivation rule · Student studies with StaffMember
∀ Student ∀ StaffMember ((Student studies with StaffMember) ↔ ∃ Course ((Student enrols in Course) ∧ (StaffMember coordinates Course)))
Student studies with Staff member if and only if Student enrols in some Course that Staff member coordinates.

# Derivation rule, every derived fact holds · Student has TotalCredits
∀ Student ∃ TotalCredits (Student has TotalCredits)
Each Student has some TotalCredits.

# Derivation rule, only derived facts hold · Student has TotalCredits
∀ Student ∀ TotalCredits ((Student has TotalCredits) → TotalCredits ≈ Sum{Credits | Course, Credits : (Student enrols in Course) ∧ (Course is worth Credits)})
If Student has TotalCredits then TotalCredits is the sum of the Credits that each Course that Student enrols in is worth.

# Derivation rule, every derived fact holds · Course has EnrolmentCount
∀ Course ∃ EnrolmentCount (Course has EnrolmentCount)
Each Course has some EnrolmentCount.

# Derivation rule, only derived facts hold · Course has EnrolmentCount
∀ Course ∀ EnrolmentCount ((Course has EnrolmentCount) → EnrolmentCount ≈ Count{Student : (Student enrols in Course)})
If Course has EnrolmentCount then EnrolmentCount is the number of Students that enrol in Course.

# Semi-derivation rule, every derived fact holds · Student has credit load TotalCredits
∀ Student ∀ Course ∀ Credits (((Student assists in Course) ∧ (Course is worth Credits)) → ∃ TotalCredits ((Student has credit load TotalCredits) ∧ TotalCredits ≈ (Credits + 5) × 2))
If Student assists in Course and Course is worth Credits then Student has credit load some TotalCredits that is (Credits plus 5) times 2.

# Uniqueness (deontic) · StaffMember mentors Student
O(∀ Student ∃^{≤1} StaffMember (StaffMember mentors Student))
It is obligatory that for each Student, at most one Staff member mentors that Student.

# Mandatory role (deontic) · StaffMember mentors Student
O(∀ Student ∃ StaffMember (StaffMember mentors Student))
It is obligatory that for each Student, some Staff member mentors that Student.

# Frequency (deontic) · StaffMember mentors Student
O(∀ StaffMember ((∃ Student (StaffMember mentors Student)) → ∃^{≤5} Student (StaffMember mentors Student)))
It is obligatory that each Staff member mentors at most 5 Students.

# Uniqueness · Person has first given PersonName
∀ Person ∃^{≤1} PersonName (Person has first given PersonName)
Each Person has at most one first given PersonName.

# Uniqueness · Person has first given PersonName
∀ PersonName ∃^{≤1} Person (Person has first given PersonName)
Each PersonName is the first given name of at most one Person.

# Mandatory role · Person has first given PersonName
∀ Person ∃ PersonName (Person has first given PersonName)
Each Person has some first given PersonName.

# Uniqueness · Person has Person -in-law
∀ Person₁ ∃^{≤1} Person₂ (Person₂ has Person₁ -in-law)
For each Person₁, at most one Person₂ has that Person₁-in-law.

# External uniqueness (outer join)
∀ CourseTitle ∀ StaffMember ∃^{≤1} Course ((Course has CourseTitle) ∧ (Course is run by StaffMember))
For each CourseTitle and Staff member, at most one Course has that CourseTitle and is run by that Staff member.

# External uniqueness (outer join): no value at position 2
∀ CourseTitle ∃^{≤1} Course ((Course has CourseTitle) ∧ ¬(∃ StaffMember (Course is run by StaffMember)))
For each CourseTitle, at most one Course has that CourseTitle and is not run by any Staff member.

# Subset (deontic)
O(∀ Student ((∃ StaffMember (StaffMember mentors Student)) → ∃ Course (Student enrols in Course)))
It is obligatory that each Student that some Staff member mentors enrols in some Course.

# Ring (irreflexive) (deontic)
O(∀ Course ¬(Course is a prerequisite for Course))
It is obligatory that no Course is a prerequisite for itself.
