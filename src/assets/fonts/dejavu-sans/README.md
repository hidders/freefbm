# DejaVu Sans (fallback diagram font)

Latin subset of DejaVu Sans, from the @fontsource/dejavu-sans package
(version 5.3.0). Bitstream Vera licence, DejaVu changes in the public domain
(see `LICENSE`).

FreeFBM uses it for diagram text when Wine Tahoma (`../wine-tahoma`) is not
there. `dejavu-sans.css` scales it so that text is about as wide as in
Tahoma: 86.9% for regular and 88.9% for bold text, measured on the names and
readings of two NORMA models (within about 1% per text).
